Third-party software in the Windows release of tos-recomp
==========================================================

This archive contains no game data. Everything below is redistributed under its own licence; the licence texts
are in the places named here.

tos-recomp, gcrecomp, To-Recomp/common
    The programs and libraries of this archive (tos-prepare.exe, tos-start.exe, toolkit/): see LICENSE
    (GPL-3.0-or-later) and the SPDX-License-Identifier line at the top of each source file.

Zig  (toolchain/zig, MIT licence: toolchain/zig/LICENSE)
    The C++ compiler tos-prepare uses on this computer ("zig c++"), and the compiler that built the libraries in
    toolkit/. Zig is an unmodified release from https://ziglang.org/download/ (the pinned version and its
    SHA-256 are in packaging/windows/zig.pin of the tos-recomp source). It includes, under their own licences, in
    toolchain/zig/lib:
      - LLVM, Clang, lld, libc++, libc++abi, libunwind, compiler-rt (Apache License 2.0 with LLVM Exceptions):
        lib/libcxx/LICENSE.TXT, lib/libcxxabi/LICENSE.TXT, lib/libunwind/LICENSE.TXT
      - mingw-w64 runtime and headers (public domain, ZPL-2.1 and BSD-style notices per file):
        lib/libc/mingw/COPYING

SDL3  (statically linked into the game, toolkit/lib/libSDL3.a; zlib licence: licenses/SDL3-LICENSE.txt)
    Copyright (C) 1997-2025 Sam Lantinga. Built from source release 3.2.28.

Disc codecs inside tos-prepare.exe (statically linked), to read compressed disc images:
    zlib      (zlib licence)
    bzip2     (bzip2 licence, BSD-style)
    liblzma   (xz; public domain)
    zstd      (BSD licence)
    Their licence files are in licenses/ (copied from the vcpkg ports that provided them).

tomlplusplus  (MIT, compiled into tos-prepare.exe through To-Recomp/common)
    Copyright (c) Mark Gillard.

The Microsoft Visual C++ runtime is linked statically into tos-prepare.exe; nothing needs to be installed.
